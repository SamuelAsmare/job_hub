# AI Usage — JobHub (Milestone 1)

## 1. AI Tools Used

- **ChatGPT:** Used for understanding Flutter concepts, discussing software architecture, explaining Riverpod, Freezed, and GoRouter, troubleshooting errors, and improving project documentation.
- **GitHub Copilot:** Used for recommendations, code explanations, navigation guidance, and assistance in understanding existing code.
- **Claude / Gemini:** Used when needed for additional explanations, architectural suggestions, and problem-solving.

## 2. How AI Was Used

- **Architecture and Project Structure:** Provided recommendations for organizing the project using feature-first architecture with `lib/core/` and `lib/features/`.
- **Navigation and Routing:** Helped explain GoRouter configuration, authentication flow, role-based navigation, and route management.
- **State Management:** Provided explanations and recommendations about Riverpod providers, repository patterns, and Freezed models.
- **UI and User Experience:** Offered suggestions for improving screen layouts, navigation, consistency, and application usability.
- **Testing and Debugging:** Assisted in understanding test failures, diagnosing errors, interpreting analyzer warnings, and suggesting possible solutions.
- **Documentation:** Helped organize and improve `PROPOSAL.md`, `MILESTONE.md`, and `AI_USAGE.md`.

## 3. Verification and Team Responsibility

- AI tools were used for recommendations, explanations, and guidance, not for generating project source code.
- All implementation decisions and code changes were made and reviewed by team members.
- The team verified the implementation using `flutter analyze --fatal-infos` and `flutter test`.
- The latest test run completed successfully with **132 passing tests**.
- No secrets, credentials, or private user data were intentionally shared with AI tools.
- Each team member is responsible for understanding, explaining, testing, and maintaining their contributions during the individual oral assessment.

## 4. Responsible Use of AI

AI tools served as learning and development assistants rather than replacements for team members' work. They helped the team understand technical concepts, evaluate different approaches, solve problems, and make informed development decisions. The team remained responsible for the implementation and final results.
